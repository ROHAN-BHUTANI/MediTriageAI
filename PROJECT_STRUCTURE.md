# Project Structure

Defines the architectural layout of the MediTriageAI repository.

`
archive/        # Historical logs, experiments, and obsolete docs
config/         # Configuration files
datasets/       # Raw and processed datasets
docs/           # Supplemental documentation
experiments/    # Current experiment trackers
models/         # Model definitions
results/        # Output artifacts and reports
scripts/        # Helper scripts for running pipelines
src/            # Core source code
tests/          # Unit and integration tests
`
