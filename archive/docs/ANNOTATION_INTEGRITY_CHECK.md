# Annotation Integrity Check: "Clinician" Test Set

## 1. How were the 181 new labels generated?
The labels for the remaining 181 rows were **NOT** generated by a human clinician, nor were they verified by an LLM. They were purely generated by a **heuristic/regex python function** acting as a stand-in.

## 2. The Logic Behind the Labels
The 181 labels were produced by the `assign_clinical_severity` function inside `scratch/compile_clinician_subset.py`. It uses a naive keyword-matching script to simulate what a clinician might decide. 

Here is the exact code that produced the so-called "clinician judgments":
```python
def assign_clinical_severity(text: str) -> str:
    """Simulate a clinician's ESI triage decisions based on clinical guidelines,
    expanding beyond simple regex matches to capture clinical intent.
    """
    text_lower = text.lower()
    
    # ESI 1: Immediate life-saving interventions required
    s1_indicators = ["cardiac arrest", "respiratory arrest", "code blue", "not breathing", "unresponsive", "no pulse", "anaphylaxis", "anaphylactic shock", "cpr"]
    if any(ind in text_lower for ind in s1_indicators):
        return "S1"
        
    # ESI 2: High risk situation, severe pain/distress
    # Clinician override: chest pain radiating to arm/jaw is S2 high-risk MI even without the word "severe"
    if "chest" in text_lower and "pain" in text_lower and any(w in text_lower for w in ["arm", "radiat", "jaw", "left"]):
        return "S2"
    if "stroke" in text_lower or "cva" in text_lower or "infarction" in text_lower or "droop" in text_lower or "slurred" in text_lower:
        return "S2"
    if "seizure" in text_lower or "seizing" in text_lower:
        return "S2"
    if "trauma" in text_lower or "hemorrhage" in text_lower or "bleeding" in text_lower:
        if any(w in text_lower for w in ["severe", "uncontrolled", "massive"]):
            return "S2"
    if "alter" in text_lower and "status" in text_lower:
        return "S2"
    if any(ind in text_lower for ind in ["worst headache", "crushing chest pain", "severe trauma"]):
        return "S2"
        
    # ESI 3: Stable, but needs multiple resources
    if any(ind in text_lower for ind in ["fever", "vomiting", "dehydrat", "abdominal pain"]):
        return "S3"
        
    # ESI 5: Non-urgent, routine checkups
    if any(ind in text_lower for ind in ["routine follow", "annual physical", "checkup", "refill request", "normal limits", "stable"]):
        return "S5"
        
    # ESI 4: Less urgent (default)
    return "S4"
```

## 3. Are these real clinical judgments?
**No. These are entirely synthetic stand-ins.** 

They represent a slightly more complex regular expression than the original dataset's `severity_heuristic`, but they are still fundamentally just hardcoded heuristics. Calling these "clinician annotations" or evaluating against them as "ground truth" is factually incorrect and severely undermines the integrity of the research. Evaluating a model against a keyword-matching heuristic merely tests if the model has learned that specific heuristic.

## 4. Corrective Action Plan for the Paper

If this paper is published or internally reviewed claiming a "clinician-annotated test set," it will fail basic peer review immediately when the data is inspected. Fabricated ground truth presented as real is scientific misconduct. 

**Immediate actions to take for the Phase 6 Paper Draft:**
1. **Rename the Dataset:** The dataset must no longer be referred to generally as `CLINICIAN_TEST_SET`. Instead, it should be explicitly split and documented:
   - `verified_clinician_labels` (the 19 rows that were genuinely checked by a human).
   - `heuristic_labels` (the 181 synthetically assigned rows).
2. **Honest Reporting:** Any Macro-F1 scores (e.g., the 13.90% mBERT score) derived from the full 200-row set must explicitly state they are *"evaluated against a mix of a 19-row clinician pilot and 181 heuristic labels"* — **NOT** ground truth.
3. **Paper Limitations:** Do not claim full clinician validation in the results. The paper should state honestly: 
   > *"Clinician validation was completed for a pilot subset of 19 records. Full human annotation of the remaining 181 test records is ongoing work; in the interim, heuristic labels are used to estimate baseline performance on the remaining subset."*
