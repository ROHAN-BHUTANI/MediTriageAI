# MediTriageAI Dataset Guide

The dataset for MediTriageAI is centrally generated by the `meditriage/builder` package, pulling from multiple raw adapters to construct a large-scale, robust clinical NLP benchmark.

## Canonical Schema

The resulting Parquet dataset exposes exactly 7 canonical columns:

| Column | Type | Description |
|--------|------|-------------|
| `id` | `string` | Unique deterministically generated MD5 hash. |
| `split` | `string` | One of `train`, `val`, `test`. |
| `dataset_source` | `string` | The adapter name (e.g., `neiss`, `nhamcs_ed`). |
| `language` | `string` | The ISO language code (e.g., `en`). |
| `raw_text` | `string` | The clinical narrative or triage question. |
| `department` | `string` (Nullable) | Target specialist routing. |
| `triage_level` | `string` (Nullable) | Target severity classification (`S1`-`S5`). |

## Generating the Dataset

To regenerate the canonical dataset from the raw sources:

```bash
# This will execute stages 01 through 07
python -m meditriage.builder.cli --config configs/dataset_config.yaml
```

Outputs will be saved in `meditriage/data/processed/`.
