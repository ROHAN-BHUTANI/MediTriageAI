# ADR-011 — Practical usefulness reported as a multidimensional report, not a composite score

**Status:** DECIDED

---

## Context

A single "most practically useful model" composite score would require an undefined, arbitrary utility function (weighting accuracy vs. latency vs. size vs. calibration).

## Decision

Report practical usefulness as a multidimensional report (routing quality, severity quality, dangerous error rate, calibration, multilingual robustness, OOD behavior, explainability, latency, resource requirements, failure modes) rather than a single score, at this stage.

## Consequences

No single "winner" can be declared on practical grounds without a reader forming their own judgment from the report — arguably more honest, but less immediately actionable as a marketing-style claim.

## Alternatives Considered

- **Defining a composite score now with placeholder weights** — rejected, an arbitrary weighting would be indistinguishable from post-hoc metric selection dressed up as objectivity.
