# Citing MediTriageAI Data Engine

If you use MediTriageAI or the datasets bundled within it for your research, please cite us as follows:

## APA
Bhutani, R. (2026). MediTriageAI Data Engine (Version 1.0.0) [Computer software]. https://github.com/ROHAN-BHUTANI/MediTriageAI

## BibTeX
```bibtex
@software{Bhutani_MediTriageAI_Data_Engine_2026,
  author = {Bhutani, Rohan},
  title = {MediTriageAI Data Engine},
  year = {2026},
  version = {1.0.0},
  url = {https://github.com/ROHAN-BHUTANI/MediTriageAI},
  note = {Multi-Task Triage, Severity Prediction, and Department Routing Model}
}
```

Additionally, please consider citing the individual datasets that you use from our curated data engine (e.g., NHAMCS, MTSamples, MedQA, etc.).
