Known Limitation: Severity Label Circularity (Audited & Addressed)

Audit Findings

Issue Identified: The classical baselines (Random Forest / Linear SVM) artificially achieve up to 93.70% severity macro-F1. Our feature importance audit revealed that ESI severity labels were generated using regular-expression heuristics, and the baseline models are simply reverse-engineering these exact keyword triggers (e.g. "normal limits", "acute distress") rather than predicting true clinical severity.

Addressed Strategy: To ensure evaluation integrity, we have flagged this baseline comparison as a dataset limitation in the research paper. The transformer models process clinical text semantically rather than relying on exact keyword matching, explaining the lower (but generalized) score.
